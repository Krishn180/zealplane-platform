# Webtoon / Manhwa Production Script: Episode 3
**Series Working Title:** *The Panopticon: Dynamite City* (पैनोप्टिकॉन: बारूद का साया)  
**Episode 3 Title:** *The Knox Chamber & The Birthday Vow* (अध्याय 3: नॉक्स चैंबर और 18वाँ जन्मदिन)  
**Format:** Vertical Scroll Webtoon / Manhwa Standard  
**Visual Style Lock:** 2D Korean Webtoon Manhwa (*Solo Leveling* / *Castle* style, razor-sharp cel-shaded inking, claustrophobic high-tension lighting, zero 3D CGI)  
**Setting:** Underground Evaluation Vault #14 (Sterile white room, glowing monitors, sealed blast doors, chemical vents)  
**Total Panels:** 35 High-Tension Cinematic Panels  
**Episode Theme:** Moral clarity under extreme psychological terror — the refusal to become a monster, outsmarting a lethal syndicate trap.
