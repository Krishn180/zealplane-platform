# ZealPlane Platform & Webtoon Slicer Creator Suite

[![Live on GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen)](https://krishn180.github.io/zealplane-platform/)
[![Official Platform](https://img.shields.io/badge/Official%20Platform-ZealPlane.com-red)](https://zealplane.com)

Welcome to the official frontend codebase and creator tools for [ZealPlane](https://zealplane.com) — India's premier open publishing platform for indie comics, webtoons, manga, and graphic novels.

## 🌟 Live Demo & Creator Tools
* **Live GitHub Pages Web App:** [https://krishn180.github.io/zealplane-platform/](https://krishn180.github.io/zealplane-platform/)
* **Official Production Platform:** [https://zealplane.com](https://zealplane.com)
* **Webtoon Slicer Tool:** Split, format, and package vertical webtoon strips into official canvas presets (800x1280 LINE Webtoon Canvas and 940x1280 Tapas) directly in your browser with zero image compression loss.

---

## 🚀 Key Platform Features

1. **Webtoon Slicer & Image Splitter**
   * Smart client-side canvas slicing with JSZip compression.
   * Auto-formats to official LINE Webtoon Canvas (800px × 1280px) and Tapas (940px × 1280px) specifications.
   * Export sliced panels instantly into numbered ZIP packages.

2. **Ultra-Responsive Reader Engine**
   * Continuous vertical scroll mode tailored for mobile and desktop reading.
   * Smart bookmarking and dwell-time tracking.
   * High-contrast next-chapter momentum and direct social sharing.

3. **Creator-First Publishing**
   * 100% intellectual property retention for indie creators.
   * Zero paywalls for readers.
   * Micro-tipping and reader coin engagement.

---

## 🛠️ Tech Stack

* **Framework:** React 18, Vite
* **Routing:** React Router v6 (SPA with static GitHub Pages 404 fallback routing)
* **Styling:** SCSS, Ant Design, Material-UI, Lucide React
* **Image Processing:** HTML5 Canvas API, JSZip, CropperJS
* **Hosting:** GitHub Pages (`github.io`) & Production VPS Nginx

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Krishn180/zealplane-platform.git
cd zealplane-platform/Frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build
```
